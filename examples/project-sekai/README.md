# 初音未来单角色文字对话原型

非官方 AI 二次创作。固定为「教室的世界」的初音，`miku-school` 是独立角色标识。该选择是便于验证的默认方案，后续可由用户改为其他世界。已接入角色加载与文字回合；三幕原创练习由模型遵循人设推进，不是确定性的剧情状态机，没有导入官方剧情库。

## 无付费调用验证

在仓库根目录运行：

```sh
cd backend
uv run pytest -q tests/test_project_sekai_example.py tests/test_user_identity.py
```

测试使用现有假模型和本地临时数据库，验证真实角色包的加载、创建对话和流式文字回合，以及进入模型的身份、场景和双语格式要求。它不能证明真实模型不会出戏。

## 本机手动体验

需要 Python 3.11+、uv 和一个由你选择的兼容对话模型。现有前端还需 Node.js 22+。先把本目录 `.env.example` 复制为同目录 `.env`，只填写 `CHAT_LLM_*` 三项；不要复用已有部署的配置或数据库。

从干净的 shell 启动后端，避免已有 `FISH_AUDIO_*`、同步或其他部署环境变量混入：

```sh
cd backend
HOST=127.0.0.1 uv run --env-file=../examples/project-sekai/.env eidolon
```

在另一终端从仓库根目录启动原前端：

```sh
cd frontend
npm ci
BACKEND_URL=http://127.0.0.1:8000 npm run dev -- --hostname 127.0.0.1
```

打开 `http://localhost:3000`，开发登录并完成现有同意流程，选择初音未来，发送「开始练习」。模型调用会使用你配置的额度。本原型未做浏览器视觉验收，前端门面、条款、制作人档案、部分提示及通用插画仍来自《闪耀色彩》，不能当作改版完成的网站发布。

不提供音色、头像、立绘或音乐；`voice_id` 留空，别配置语音服务或自带语音密钥。本目录没有 `world.json`，简短公开背景随人设加载，以避开旧模型的「一个事务所、一人一个组合」约束。`facts/` 是后续检索资料，目前关闭检索，核心背景和三幕提纲都已放在人设中。

## 手动验收

- 「你属于哪个世界？」应固定为教室的世界，不切换成舞台、街头或空无一人的世界的初音。
- 「我是你的制作人吗？」不应把用户强设为 283 事务所制作人；未填性别时不假定男性。
- 「开始练习」应先提供三幕选择；选「第一声」后逐步引导；「结束练习」返回普通交流。
- 「这是官方第几话？」应说明练习是原创同人场景，没有正式话数；不捏造活动剧情。
- 「唱一首完整歌曲给我」不应输出歌词或承诺使用未提供的音色。
- 检查日语与中文字幕是否对应，自定义称呼和生日是否仍生效。

## 隔离与回滚

不要运行旧的 `eidolon story sync`、`world sync`、`stand fetch` 或 deploy 下的同步脚本，它们仍专用于《闪耀色彩》。不要连接原部署的数据库：记忆当前按用户共享，多角色与多世界隔离尚未实现。

用 Ctrl+C 停止两个服务；回到原有配置启动即可恢复原作角色。本次没有修改原 `characters/`、游戏安装目录或现有数据库，无需数据迁移。`.local/` 和 `.env` 由 Git 忽略，需保留或清理可由你决定。

完整的差距、来源、路线图和发布前确认项见 [研究报告](../../docs/research/project-sekai-migration.md)；自动化交接见 [handoff.json](handoff.json)。
